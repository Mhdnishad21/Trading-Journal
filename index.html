Settings & backup

CSV backup

Export all trade fields, checklist selections, mental states and screenshot-present flags to a CSV file that opens in Excel. Image files themselves are included in the full JSON backup, not embedded in CSV.

Restore full backup

Import a JSON backup exported by this app. Import replaces data currently stored on this device.

Delete all data

Permanently removes trades and screenshots from this browser on this device. Export a backup first if needed.

Storage and privacy

  • Records and screenshots are stored in this browser on this device.
  • iPhone and Windows browser data are separate and do not sync automatically.
  • Large screenshots may reach browser storage limits; image resizing is applied, but keep backups.
  • CSV includes screenshot-present flags; use JSON backup to preserve the actual screenshots.
  • This app does not connect to a broker or send trade data to a server.
